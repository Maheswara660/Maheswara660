## 🚀 Featured Projects

### 📦 Packora

> ⭐ **Focus:** Convert any website or web app into a polished native Android application in minutes.

Packora is a modern Android application that transforms websites and web apps into installable APKs with custom app icons, splash screens, permissions management, native Android configurations, and a smooth app generation workflow.

**Tech Stack:** `Kotlin` • `Jetpack Compose` • `MVVM` • `Clean Architecture` • `Room` • `Hilt` • `Android`

[![View Repository](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Maheswara660/Packora)

### 📁 Filora

> ⭐ **Focus:** A modern Android file manager built for fast and efficient file management.

Filora provides file browsing, search, copy/move operations, archive support, storage analysis, and a clean Material Design experience.

**Tech Stack:** `Kotlin` • `Jetpack Compose` • `MVVM` • `Room` • `Storage APIs` • `Android`
