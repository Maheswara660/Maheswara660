## 💼 About Me

I'm a **Final-Year Computer Science and Engineering student** focused on mobile application development, currently expanding my skills in **Flutter and Dart**.

My previous development experience includes building Android applications using **Kotlin, Jetpack Compose, MVVM, and Room Database**. I'm now exploring cross-platform development with Flutter, focusing on responsive interfaces, reusable widgets, and maintainable application architecture.

I enjoy learning through practical projects, experimenting with technologies, and contributing to open-source software.

- 📱 **Flutter & Dart:** Learning to build responsive cross-platform mobile applications.

- 🏗️ **Application Architecture:** Learning maintainable code organization and software design principles.
- ⚡ **Android Development:** Previous hands-on experience with Kotlin, Jetpack Compose, MVVM, and Room.
- 🌐 **Open Source:** Building practical projects and collaborating with the developer community.
