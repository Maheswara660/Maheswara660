## 💼 About Me

I am a **Final Year Computer Science Student** actively learning and building native mobile applications focused on **Android Development**.

My core learning stack centers around **Modern Android Development (MAD)** practices—building reactive, maintainable applications with **Kotlin**, **Jetpack Compose**, **Clean Architecture**, **Coroutines**, **Hilt**, and **Room**. To **future-proof** my mobile engineering journey, I am actively exploring **Kotlin Multiplatform (KMP)** and **iOS development (Swift)**.

### 🌟 Core Strengths & Learning Focus
- 📱 **Modern UI Development:** Building responsive, declarative user interfaces with Jetpack Compose & Material Design 3.
- 🏗️ **Architecture & Best Practices:** Applying MVVM + Clean Architecture principles for testable and decoupled code.
- ⚡ **Reactive Workflows:** Learning Kotlin Coroutines, StateFlow/SharedFlow, and async background processing.
- 🔮 **Future-Proofing:** Exploring Kotlin Multiplatform (KMP) and iOS development with Swift.
